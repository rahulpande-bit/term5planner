Owner tools

Manage users
Block or unblock someone by their email. A blocked account can't sign in, and gets signed out — with a clear message — within about a minute if they're already using it.
Sign-in log
Downloads two files: a summary (who's registered, their attendance %, whether they're below 80% — your 20%-leave cap), and a full detail file with every session anyone's ever marked. The detail file is structured so a future "import attendance" feature could read it straight back in, if that's ever needed. Note: these numbers only reflect what each student chose to mark in this app, not official college records. Builds fresh each export — nothing extra is stored.
Fix a wrong identity
Picking a name is permanent for each student — there's no self-service "change who you are," on purpose, so one account can't be passed around a group taking turns. If someone genuinely picked the wrong name by mistake, clear it here — they'll be asked to pick again next time they open the app.
Owner passcode

Everyone signs in with their own email and a password they set themselves — no codes to hand out anymore, and no limit on how many devices one account can be used from. One student can only ever be linked to one email; the app won't let a second account claim a name that's already taken. Note: email here isn't verified (no confirmation link) — it's a real login, just not one this app can confirm you actually own that inbox.

This planner only uses schedule and roster information the college already shared with the batch (like the course nominal-list email) — nothing was accessed that wasn't already available to students. No private or restricted data has been used.
